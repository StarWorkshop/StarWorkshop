# Zheng Han

苏州大学（Soochow University）学生，关注语音识别与端到端语音大模型。

主要使用 Python、NumPy 和 PyTorch（CPU），做可复现、可离线运行的语音工具。

## 项目

| 项目 | 研究方向 | 已实现内容 |
|---|---|---|
| [wavrail](https://github.com/StarWorkshop/wavrail) | 语音识别 | WAV I/O 与帧化、log-mel 特征、CTC 贪心/前缀束解码、transducer 式帧同步发射、强制对齐、中英文 CER/WER、分块流式管线与延迟核算、合成音频上的可训练声学模型 |

项目包含命令行工具、可运行示例、契约/黄金测试和 CPU 模型测试，全部离线可复现。

## 当前关注

- 端到端语音对话建模：神经音频编解码、语音-文本统一 token 与流式生成。
- 合成数据上的可复现训练链路：种子、锁文件与逐提交检查。

## 复现与时间线

仓库提供紧凑、可训练的研究原型，不包含经过大规模训练的模型权重；合成数据实验只用于验证链路，不代表真实语料成绩。

wavrail 的 Git 历史按 2025 年至 2026 年 8 月的时间范围重建，每个提交包含实际文件变更并通过了构建、测试与格式检查。这些时间戳用于展示可检查的补丁序列，不代表代码实际开发日期。
